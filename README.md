## F1 Tracker

A mobile application for following Formula 1, built with **React Native** and **JavaScript**. Using firebase as backend.

Live project: f1-tracker-93afa.web.app

### Main responsibility
My main responsibility in this project was to handle the backend, with database and its connection to the site. In addition to create the login functionality and corresponding views.
